# План Mini App (Telegram Web App)

Mini App — веб-приложение внутри Телеграма, открывается кнопкой бота.
Уже есть каркас: `frontend/dashboard.html`, `frontend/app.js`, `frontend/styles.css`.
Ниже — что в нём должно быть, с привязкой к уже написанному бэкенду.

## Экраны

### 1. Дашборд (главный)
- Баланс (через CCXTExecutor.get_balance / TON Connect)
- Открытые позиции + PnL (реальный, С комиссиями — как в PaperExecutor)
- Статус бота: активные стратегии, последняя сделка, kill-switch
- Тикеры, по которым идёт торговля

### 2. Стратегии (управление плагин-движком)
Зеркалит `StrategyRegistry` + `StrategyEngine`:
- Список стратегий (ma_cross, ai_news, будущие) с переключателями ВКЛ/ВЫКЛ
- Ползунок ВЕСА стратегии (влияет на взвешенный ансамбль)
- Показ фильтров: мин. сумма, комиссия, лимит % позиции (почему сделка
  не исполнилась — прозрачность для юзера)
- Кнопка "Добавить стратегию" (загрузка/выбор из каталога) — точка расширения

Эндпоинты уже есть: `GET /api/strategies`, `POST /api/strategies/{name}/enable`,
`POST /api/strategies/{name}/weight`.

### 3. Исполнитель (Executor)
- Выбор режима: **Paper** (песочница, без денег) / **CCXT** (реальная биржа)
- Безопасный ввод API-ключа биржи: в браузере, шифруется перед отправкой,
  НЕ пишется в логи. Хранится в зашифрованном виде (например, в БД под
  пользователя, ключ сессии из Telegram initData)
- Переключатель `Testnet mode` (торговля на песочнице биржи)
- (позже) TonConnect — подключение TON-кошелька кнопкой

### 4. Новости + ИИ
- Лента новостей с сентиментом (от ai_news + локальный llama.cpp)
- Кнопка "Скормить фото новости" → нейронка читает (vision) — поле
  `images_b64` в `LLMClient.analyze_sentiment` уже готово
- Показ вердикта (BUY/SELL/HOLD) и почему

### 5. История сделок + аналитика
- Массовый анализ своих сделок: win-rate, средний PnL, комиссии (как в ТЗ)
- Эти метрики подпитывают решения стратегий (feedback loop) — пока задел в
  БД (SQLAlchemy), движок пока их не читает, но структура готова
- Графики (через lightweight-charts или canvas)

### 6. Настройки риска (критично для микро-депозита!)
- Макс. % позиции (`max_position_pct`, уже в движке = 0.95)
- Мин. сумма сделки (`min_trade_usdt` = 1.0)
- Kill-switch баланса (`min_balance_usdt` = 1.0) — торговля на паузе при
  падении баланса ниже $1
- Таймфрейм, список тикеров

## Как ляжет на архитектуру
```
Mini App (frontend/)  --HTTPS-->  FastAPI (backend_python/)
  - кнопки ВКЛ/ВЫКЛ              - /api/strategies (registry)
  - баланс/позиции               - /api/trading/execute (CCXTExecutor)
  - ввод API-ключа               - auth по Telegram initData
        |
        v
  StrategyEngine (ансамбль + комиссии + микро-защита)
        |
        v
  Executor: Paper | CCXT | (TonConnect)
        |
        v
  Биржа (ccxt)  |  TON-кошелёк (TON Connect)
```

## Что делать ДАЛЬШЕ (по приоритету)
1. Дописать `frontend/app.js`: экран Стратегий (drag переключателей →
   `/api/strategies/{name}/enable`)
2. Экран Исполнитель: форма ввода API-ключа биржи (безопасно)
3. Дашборд: баланс/позиции через CCXTExecutor
4. История + аналитика (графики)
5. TonConnect (позже)

## Безопасность (важно!)
- API-ключ биржи НИКОГДА не показываем обратно в UI в открытом виде
- Только права trade, без withdraw
- auth Mini App через `initData` (HMAC от bot token) — иначе кто угодно
  сможет управлять ботом
